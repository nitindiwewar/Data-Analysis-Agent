# Annual Security & Compliance Report 2024
## Section 1: Executive Summary
In Q3 2024, our cloud infrastructure blocked 45,200 malicious penetration attempts across APAC servers. 
The Mean Time to Detect (MTTD) decreased from 14 minutes to 3.2 minutes following the rollout of the eBPF kernel telemetry monitor.

## Section 2: Financial Impact & Risk
Security incident mitigation prevented an estimated \.2 Million in potential data breach damages.
The total compliance budget allocated for FY2025 is \.85 Million, representing a 22% increase over FY2024.

## Section 3: Recommendations
1. Upgrade legacy MySQL clusters to version 8.0 with TLS 1.3 enforced.
2. Implement hardware security keys (FIDO2/WebAuthn) for all DevOps staff with production access.
